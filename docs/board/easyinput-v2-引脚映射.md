# EasyInput V2 引脚映射（适配 xiaozhi-esp32）

> 所有事实来自 `easyinput-board-cy` 硬件合同（pinout.md / power-and-peripherals.md / identity-and-authority.md）。
> 板型身份：EasyInput V2.0 = 固件别名 `v2` = PCB 丝印 `AI Keyboard V2.1`（同一套硬件基线）。
> SoC：ESP32-S3R8，8MB Octal PSRAM，16MB Flash，原生 USB（GPIO19/20）。

## 主按键（低有效，板载上拉）
| 按键 | GPIO | 备注 |
| --- | --- | --- |
| S1 | 2 | **主交互键**（单击=对话开/关；开机态=进入配网） |
| S2 | 47 | v1 未绑定 |
| S3 | 38 | v1 未绑定 |
| S4 | 41 | v1 未绑定 |
| S5 | 1 | v1 未绑定 |
| S6 | 6 | v1 未绑定 |
| S7 | 7 | v1 未绑定 |
| S8 | 48 | v1 未绑定 |

> **GPIO0 不是 S5，也不是任何产品键**——它是 BOOT0 下载入口。

## 编码器与唤醒
| 功能 | GPIO | 语义 |
| --- | --- | --- |
| 旋钮 A | 17 | 正交相位，内部上拉 |
| 旋钮 B | 16 | 正交相位，内部上拉 |
| 旋钮按压 S9 | 18 | 独立低有效键（=对话开/关） |
| KEY_WAKE | 21 | 二极管 OR 汇总低有效唤醒线；只表示「有输入」，不标识来源，v1 不用于消抖 |

## LED 与共享电源
| 功能 | GPIO | 有效电平 / 格式 |
| --- | --- | --- |
| WS2812 串行数据 | 12 | GRB，5 颗串联 |
| 共享外设电源使能 PWR_EN | 8 | **高有效**，控制 LED/麦克风/扬声器供电域 |
| 绿色状态灯 | 42 | 高有效（系统就绪指示） |

> GPIO8 控制 LED/麦克风/扬声器共享域，**不是「LED 开关」**。冷启动必须先锁存输出为低→拉高→等电源稳定→再初始化 WS2812/麦/扬声器 I2S。

## 电池 / 充电 / USB
| 功能 | GPIO | 方向 / 有效电平 |
| --- | --- | --- |
| 分压使能 SEN_EN | 5 | 输出，高有效（v1 常开） |
| 电池采样 SEN_VBAT | 4 (ADC1_CH3) | 模拟输入，约 VBAT/2 |
| 外部供电检测 SEN_VIN | 40 | 上拉输入，低=外部供电存在 |
| 充电状态 SEN_CHRG | 39 | 上拉输入；仅外部供电时 1=充电中，0=充满 |
| USB D-/D+ | 19 / 20 | ESP32-S3 原生 USB（ROM 下载用） |
| BOOT0 | 0 | 专用下载电路，非产品键 |

## 音频（独立 I2S 时钟线 → NoAudioCodecSimplex）
| 外设 | 信号 | GPIO |
| --- | --- | --- |
| 麦克风 | BCLK / WS / DIN | 9 / 10 / 11 |
| 扬声器(MAX98357A) | BCLK / WS / DOUT | 14 / 13 / 15 |

> MAX98357A 免 I2C，无 MCLK；采样率/位宽/槽格式由本项目定，需实板验证。

## 保留与调试
- GPIO26–37 为 Flash/PSRAM 总线，保留。
- 调试串口 J4：1=3V3、2=RXD0(GPIO44)、3=TXD0(GPIO43)、4=GND。
